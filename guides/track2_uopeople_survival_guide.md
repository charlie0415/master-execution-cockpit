## 2. The 10/10 Discussion Forum Blueprint

UoPeople discussion grading is heavily peer-assessed. To consistently secure full marks:

1. **Structure Your Initial Post:**
   * **Paragraph 1:** Clear thesis statement answering the prompt directly.
   * **Paragraph 2 & 3:** Concrete technical explanation with a real-world code snippet or diagram.
   * **Paragraph 4:** Critical evaluation / trade-offs (e.g., Big-O time vs space complexity, scalability).
   * **References:** Minimum 2 academic citations in **APA 7th Edition** format.
2. **Peer Replies (Minimum 3):**
   * Do not write: *"Great post, I agree with you!"* (You will be scored low).
   * Use the **Praise-Question-Extend** formula:
     * *Praise:* "I appreciated your explanation of Dijkstra's algorithm using priority queues..."
     * *Question:* "How would your approach adapt if negative edge weights are introduced?"
     * *Extend:* "In such instances, Bellman-Ford or Johnson’s algorithm might provide better convergence at the cost of O(V*E) complexity."

## 3. Programming Assignment Rubric Mastery

UoPeople instructors and peer evaluators grade against strict rubrics. Ensure your submissions contain:

* **Clean Code Structure:** PEP 8 compliance for Python, proper header comments for C++ / Java.
* **Header Comment Block:**
  ```python
  """
  Course: CS 2203 - Databases 1 / CS 3303 - Data Structures
  Student: Charles Oluwatuase
  Assignment: Unit 4 Programming Assignment
  Date: October 2026
  Description: Implementation of AVL tree balancing with rotational tests.
  """
  ```
* **Comprehensive Docstrings & In-Line Comments:** Explain *why* a particular algorithm was chosen, not just *what* the syntax does.
* **Test Case Coverage:** Always include a dedicated `test_main()` function with at least 3 distinct test scenarios (Normal case, Edge case / Empty input, Exception case).
* **PDF Submission with Screenshots:** Combine your code, explanation, and terminal output screenshots into a clean, professional single PDF.

1. **Do not panic or argue in public forums.**

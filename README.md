## 📱 How to Use on Your Phone & Laptop (Free Hosting on GitHub Pages)

You can host this entire interactive cockpit **100% free on GitHub Pages** in 2 minutes. Once hosted, you can open your live URL on your iPhone, Android, and laptop, install it as an app on your home screen, and sync your progress seamlessly!

### Step 1: Create a GitHub Repository
1. Log into your GitHub account: [github.com/new](https://github.com/new).
2. Name the repository: `master-execution-cockpit` (or any name you prefer).
3. Set visibility to **Public** (or Private if you have GitHub Pro for Pages).
4. Do NOT initialize with a README (this folder already has everything).

### Step 2: Push This Directory to GitHub
Open your terminal in this folder and run:
```bash
git init
git add .
git commit -m "Initial commit of Master Execution Cockpit"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/master-execution-cockpit.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. On your GitHub repository page, click **Settings** (top right tab).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment > Branch**:
   * Select `main` branch.
   * Folder: `/ (root)`.
   * Click **Save**.
4. In about 60 seconds, GitHub will give you your live URL:
   ```
   https://<YOUR_GITHUB_USERNAME>.github.io/master-execution-cockpit/
   ```

### Step 4: Install as an App on Your Mobile Phone
1. Open your live URL on your phone in **Safari** (iPhone) or **Chrome** (Android).
2. On iPhone: Tap the **Share button** (square with arrow) -> Select **"Add to Home Screen"**.
3. On Android: Tap the **Three Dots menu** -> Select **"Install App"** or **"Add to Home Screen"**.
4. You now have a native full-screen app on your phone that works even when completely offline!

## 🔄 Cross-Device Cloud Syncing (Laptop ⇄ Phone)

The Cockpit includes two built-in ways to keep your laptop and phone perfectly synced:

### Method A: One-Click Sync Code (Zero Configuration)
1. On your laptop, click **"🔄 Cloud / Sync"** in the top bar.
2. Click **"Generate Sync Code"** and tap **Copy**.
3. Send it to your phone (via WhatsApp, Telegram, or email).
4. Open the Cockpit on your phone, paste the code into the box, and tap **"Apply Sync Code"**. All 24 weeks are instantly synchronized!

### Method B: GitHub Gist Cloud Sync (Fully Automated)
1. Create a GitHub Personal Access Token with `gist` permissions at [github.com/settings/tokens](https://github.com/settings/tokens).
2. In the Cockpit, enter your token and click **"Push to Cloud Gist"**.
3. On your phone, enter the same token and tap **"Pull from Cloud Gist"** anytime to fetch your latest progress!
